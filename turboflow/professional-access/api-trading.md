# API Trading

### Overview

The TurboFlow Trading API provides programmatic access for professional and high-volume traders looking to integrate TurboFlow into their trading systems and workflows.

**API access is currently in beta and available to approved users only.**

### Eligibility

Accounts with **more than $100,000 in cumulative trading volume** are eligible to apply for API access.

Meeting the eligibility requirement does not guarantee approval. Applications are reviewed individually based on TurboFlow’s current access criteria and technical availability.

### How to Apply

To apply for API access, email [contacts@tf.xyz](mailto:contact@tf.xyz)  and include:

* Your TurboFlow UID
* Your account email

The TurboFlow team will review your application and follow up with eligible applicants.

### Important Notice

API access is currently in beta. Availability, eligibility requirements, supported functionality, and access conditions may change as the program develops.

For the latest information or API access enquiries, contact [contacts@tf.xyz](mailto:contact@tf.xyz)&#x20;
