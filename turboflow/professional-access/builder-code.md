# Builder Code

### Overview

Builder Code is designed for selected businesses and builders looking to integrate supported TurboFlow products and liquidity into their own platforms.

Approved partners can access supported integration capabilities, with commercial terms determined on a case-by-case basis depending on the products and services involved.

### Who Can Apply

Builder Code is intended for businesses and builders with a clear integration use case for TurboFlow’s products or liquidity.

Applications are reviewed individually based on the proposed integration, operational capabilities, and current availability.

### How to Apply

If you are interested in building with TurboFlow, email [contacts@tf.xyz](mailto:contact@tf.xyz) and include relevant information such as:

* Company name and website
* Intended integration or use case
* Products or services you are interested in
* Relevant technical or operational capabilities

The TurboFlow team will review your enquiry and follow up where there is a potential fit.

### Commercial Terms

Builder Code pricing and commercial arrangements are determined on a case-by-case basis.

Terms may vary depending on the products, services, integration scope, and requirements involved.

### Important Notice

Builder Code access is subject to review and approval. Supported integrations, availability, technical requirements, and commercial terms may change over time.

For Builder Code enquiries, contact [contacts@tf.xyz](mailto:contact@tf.xyz)
